# 🛸 드론 비행구역 확인

취미로 드론(초경량비행장치)을 날리는 사람을 위한 웹앱입니다.
지금 있는 곳이나 지도에서 누른 지점이 **비행금지구역·비행제한구역·관제권**인지 확인해 줍니다.
날씨, 비행 기록, 비행 전 점검표도 함께 들어 있습니다.

> ⚠️ **참고용입니다.** 국토교통부 공간정보(V-World) 데이터를 사용하며, 임시 비행금지(행사·훈련 등)나 최신 변경 사항은 늦게 반영될 수 있습니다. 비행 전에는 반드시 [드론 원스톱 민원서비스](https://drone.onestop.go.kr)에서 확인하세요.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 📍 내 위치 판정 | GPS 위치로 비행 가능 / 승인 필요 / 불가 판정 |
| 🗺️ 지도에서 판정 | 지도 아무 곳이나 누르면 그 지점을 판정 |
| 🔍 주소·장소 검색 | 도로명·지번 주소, 장소 이름, 동 이름으로 검색 |
| 🚧 주변 공역 안내 | 반경 5km 안의 금지·제한구역과 거리 표시 |
| 🌤️ 날씨 | 풍속·돌풍·강수·일출/일몰, 야간 비행 경고 |
| ☆ 장소 저장 | 자주 가는 비행 장소를 저장해 검색창에서 바로 선택 |
| ⏱ 비행 타이머 | 비행 시작~종료 시간을 재고 자동으로 기록 작성 |
| 📒 비행 기록 | 일시·장소·기체·시간·고도·배터리·메모, 통계 |
| 💾 백업·내보내기 | 엑셀(CSV) 내보내기, 백업 파일 저장·불러오기 |
| ✅ 비행 전 점검표 | 공역·날씨·기체·비행 중 체크리스트 |
| 📱 앱처럼 설치 | 휴대폰 홈 화면에 추가 가능(PWA) |

| 색 | 공역 (V-World 레이어) | 판정 |
|---|---|---|
| 🔴 | 비행금지구역 `LT_C_AISPRHC`, 관제권 `LT_C_AISCTRC` | 비행 불가 (승인 필요) |
| 🟠 | 비행제한구역 `LT_C_AISRESC`, 위험구역 `LT_C_AISDNGC` | 비행승인 필요 |

## 설치 방법 (GitHub Pages)

### 1. V-World 인증키 발급
1. [브이월드](https://www.vworld.kr) 회원가입 → **인증키 → 인증키 발급**
2. 활용 API: **2D 데이터 API, 검색 API, 주소(Geocoder) API, WMS/WFS, WMTS/TMS** 모두 체크
3. 서비스 URL: `https://내아이디.github.io` (GitHub Pages 주소)
4. 발급 즉시 키가 나옵니다.

### 2. GitHub에 올리기
1. GitHub에서 새 저장소 만들기 (예: `dronezone`, **Public**)
2. **Add file → Upload files** 로 이 폴더의 파일 전부(`icons` 폴더 포함) 업로드
3. `config.js`를 열어 연필 아이콘으로 수정 → `VWORLD_KEY: '발급받은키'` 입력 후 Commit
4. **Settings → Pages → Branch: main / (root) → Save**
5. 1~2분 뒤 `https://내아이디.github.io/dronezone/` 에서 열림

> 인증키를 `config.js`에 넣지 않고 앱의 **[안내] 탭 → 설정**에서 입력해도 됩니다(그 기기에만 저장).
> 브이월드 키는 등록한 도메인에서만 동작하므로 공개 저장소에 올려도 다른 사이트에서 도용하기 어렵습니다.

### 3. 휴대폰에 설치
- **아이폰(Safari):** 공유 버튼 → 홈 화면에 추가
- **안드로이드(Chrome):** 메뉴(⋮) → 홈 화면에 추가 / 앱 설치

## 문제 해결
- **"판정할 수 없음"이 뜸** → 인증키, 브이월드에 등록한 서비스 URL, 활용 API 체크 여부를 확인하세요.
- **공역 색이 지도에 안 보임** → 오른쪽 위 레이어 버튼에서 켜고 끌 수 있습니다. 군작전구역은 범위가 넓어 기본으로 꺼져 있습니다.
- **내 위치가 안 잡힘** → `https://` 주소에서만 위치 기능이 동작합니다. 브라우저 위치 권한을 허용하세요.
- **비행 기록이 사라짐** → 기록은 브라우저에만 저장됩니다. 주기적으로 [기록] 탭 → 백업 파일 저장을 해 두세요.
