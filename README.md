# 🛸 하코 NFZ 조회

**👉 https://moto2345.github.io/nfz/**

취미로 드론을 날리는 분들을 위한 비행구역 확인 앱입니다.
지금 있는 곳이나 지도에서 누른 곳이 **비행금지구역·비행제한구역·관제권**인지 확인하고, 날씨와 야간 여부까지 합쳐서 **지금 날려도 되는지** 알려줍니다.

> ⚠️ **참고용입니다.** 국토교통부 공개 공역 정보를 바탕으로 하지만 임시 비행금지(행사·훈련 등)나 최근 변경 사항은 늦게 반영될 수 있습니다. 실제 비행 전에는 꼭 [드론 원스톱 민원서비스](https://drone.onestop.go.kr)에서 확인하고 필요한 비행승인·촬영허가를 받으세요.

## 📱 휴대폰에 설치하기
앱스토어 설치 없이 홈 화면에 추가해서 앱처럼 쓸 수 있어요.
- **안드로이드 (삼성 인터넷·크롬)**: 위 주소 접속 → 메뉴(⋮ 또는 ≡) → **홈 화면에 추가**
- **아이폰 (사파리)**: 위 주소 접속 → 공유 버튼 → **홈 화면에 추가**

처음 ⌖ 내 위치 버튼(지도 오른쪽 아래)을 누를 때 위치 권한을 **허용**해 주세요.

## 사용법

### 🗺️ 지도
- **⌖ 내 위치 버튼**: 지금 내 위치가 비행 가능한지 확인
- **지도 누르기**: 누른 곳이 비행 가능한지 확인
- **핀 말풍선**: 확인한 지점의 핀 위에 속한 구역과 판정(예: ⛔ 비행금지구역 · 비행 불가)이 바로 떠요. 말풍선을 누르면 접어둔 결과창이 펼쳐져요
- **검색창**: 주소·장소 이름·동 이름으로 검색. 검색창을 누르면 최근 검색한 곳과 저장한 장소가 나와요
- **주변 공역**: 5km 안의 금지·제한구역과 거리를 알려주고, 1km 안이면 따로 경고해요
- **🔔 항공고시보(NOTAM)**: 행사·훈련 등으로 생기는 임시 비행금지·제한 구역 중 드론 관련만 30분마다 가져와 지도에 표시하고 판정에도 반영해요
  - 지금 활성인 구역은 빨간 점선, 시간제(지금은 비활성)·곧 시작하는 구역은 주황 점선
  - 앱을 열면 확인한 곳 40km 안의 것만 알림창으로 알려줘요("오늘 하루 보지 않기" 가능)
  - 맨 위 🔔 버튼: 다시 보기, **전국 목록 보기**, 🗺 지도에서 보기
  - 시간제 구역은 앞으로의 활성 시간을 한국시간으로 보여줘요 (예: 9/26(내일) 11:00~13:00)
- **날씨**: 바람·돌풍·기온·강수·일출/일몰. 밤이거나 바람이 세면 판정에 바로 반영돼요
- **내 기체 고르기**: 날씨 칸에서 기체(DJI Mini 3·4·5 Pro, Mavic 3·4 Pro, Avata 2, Inspire 2·3 등)를 고르면 그 기체의 내풍 한계에 맞춰 강풍을 판정해요. 비행 기록의 기체 칸에도 자동으로 들어가요
- **☆ 장소 저장**: 자주 가는 비행 장소 저장
- **📋 좌표·주소 복사**: 주소·좌표·해당 공역을 한 번에 복사 → 드론 원스톱 비행승인 신청서에 붙여넣기
- **오른쪽 위 레이어 버튼**: 일반지도/위성지도 전환, 공역 표시 켜고 끄기
- **⟳ 버튼 (맨 위 오른쪽)**: 새로고침. 보던 곳을 다시 확인하고 날씨도 새로 받아와요

### 📒 기록
- **⏱ 비행 시작 → 비행 종료**: 비행 시간을 재고, 끝나면 장소·시간이 채워진 기록 창이 떠요
- 기체·최대고도·배터리·메모를 남기고, 총 비행 횟수·시간을 볼 수 있어요
- **엑셀(CSV) 내보내기**와 **백업 파일 저장·불러오기** 지원

### ✅ 점검
- 비행 전 점검표 16개 항목 (허가 / 날씨·현장 / 기체 / 비행 중)

### ℹ️ 안내
- 판정 색 설명, 취미 비행 기본 수칙
- 드론 원스톱 신청 종류별 처리 기간
- 사전 협의가 필요한 장소, 신고·문의 전화번호

## 판정 보는 법

| 판정 | 뜻 |
|---|---|
| ⛔ **비행 불가 (승인 필요)** | 비행금지구역·관제권(공항 주변)·진행 중인 항공고시보 임시비행금지 구역. 승인 없이는 못 날려요 |
| 🟠 **비행승인 필요** | 비행제한구역·위험구역 등. 드론 원스톱에서 승인을 받아야 해요 |
| 🟡 **주의 — 확인 후 비행** | 국립공원·경계구역 등. 비행 전에 확인이 필요해요 (군작전구역은 취미 비행 가능으로 판정) |
| ✅ **비행 가능 · 비행승인 불필요** | 조종자 준수사항(낮·25kg 이하·150m 미만·눈에 보이는 범위)만 지키면 돼요 |
| 🌙 **공역은 비행 가능 · 지금은 야간** | 장소는 괜찮지만 지금이 밤이거나 날씨가 나빠서 비행하면 안 돼요 |

> 승인이 필요한 곳에서 승인 없이 날리면 **과태료 150만원**(1차 위반)입니다.

## 꼭 지켜야 할 기본 수칙
- 고도 150m 미만, 눈으로 보이는 범위에서만 비행
- 일몰 후~일출 전 야간 비행 금지 (특별비행승인 시 예외)
- 사람이 많이 모인 곳 위로 비행 금지
- 음주 비행 금지, 비행 중 물건 떨어뜨리기 금지
- 사진·영상 촬영은 비행승인과 별도로 **항공촬영 허가**가 필요할 수 있어요
- 사유지, 해수욕장, 국립공원, 문화재, 군부대 등은 관리자와 **미리 협의**하세요

## 자주 묻는 질문
- **예전 화면이 보여요** → 맨 위 ⟳ 버튼을 누르거나 앱을 완전히 닫았다가 다시 여세요.
- **내 위치가 안 잡혀요** → 휴대폰 위치(GPS)를 켜고 브라우저 위치 권한을 허용하세요.
- **비행 기록이 사라졌어요** → 기록은 내 휴대폰 브라우저에만 저장돼요. 브라우저 데이터를 지우거나 휴대폰을 바꾸기 전에 [기록] 탭 → 백업·내보내기에서 백업해 두세요.
- **다른 사람이 내 기록을 볼 수 있나요?** → 아니요. 기록과 저장한 장소는 각자의 휴대폰에만 저장돼요.
